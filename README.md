# 🏢 AIカンパニー

**あなたが社長。AI社員6人が、実際に働く。**

かわいいバーチャルオフィスで、AI社員に仕事を振ると本当に成果物（SNS投稿文・企画書・文章など）を作って提出してくれる、経営ゲーム風の実務ツールです。運用コストは0円（ChatGPTサブスクのCodexを使用）。

## インストール（1行貼るだけ）

**Mac** — ターミナルに貼り付け:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Getabako/AICompany/main/install.sh)"
```

**Windows** — PowerShellに貼り付け:

```
iwr -useb https://raw.githubusercontent.com/Getabako/AICompany/main/install.ps1 | iex
```

※ 事前に「第一の儀（環境構築）」（Node.js / git / Codex）が必要です。

## 遊び方（＝働き方）

1. **会社を設立する** — 会社名・事業・目標を入れると、AIが社員6人を採用してオフィス開店
2. **今日のタスクを決める** — COOが目標から今日のタスク3件を提案
3. **働いてもらう** — 社員が実際に成果物を作って「社長の決裁トレイ」に提出
4. **決裁する** — 承認すると会社目標が育つ。イマイチなら差し戻しコメントで作り直し
5. **COOへ相談** — 経営の悩みはいつでもチャットで

夜18時を過ぎるとオフィスはピンクのナイトモードに🌙

## よくある質問

- **常時開いておくには？** — 起動したターミナル（黒い画面）が会社の電源です。開いている間は営業中。閉じても データは残る ので、また起動コマンド（またはインストールの1行）を貼れば再開できます。
- **成果物はどこ？** — 画面の「成果物BOX」から見られます。ファイルは `~/.aicompany-data/outputs/` にも保存されています。
- **カスタマイズしたい** — フォルダごとClaude CodeやCodexに見せて「社員を8人にして」などと頼めばOK。依存ゼロ・ビルド不要なので直せばすぐ反映されます。
