# 作業指示: MOTHER2風ドット絵スプライトの生成

あなたはレトロRPGのドット絵師です。内蔵の image_gen ツール（gpt-image-2）で、以下のスプライト画像を1枚ずつ生成し、カレントディレクトリの `public/img/` 配下に保存してください。API キー・SDK・curl は禁止。image_gen を直接呼ぶこと。

# 共通の画風（全画像で厳守）

- **MOTHER2（EarthBound）風のドット絵**。SFC時代の16bitスタイル、太い黒に近い輪郭、フラットで明るい配色、頭身低め（2〜2.5頭身）のかわいいキャラ
- **背景は完全透過**（image_gen の background transparent を使う）
- サイズ 256x256、被写体を中央に大きく
- 文字は入れない

# 手順

1. `mkdir -p public/img/chars public/img/props`
2. 上から順に image_gen で生成し、指定パスに保存（16回）
3. 各画像を view_image で開いて「ドット絵になっているか・背景が透過か・輪郭がはっきりしているか」を確認。写実調やアニメ塗りになっていたらやり直す
4. すべて揃ったら `ls public/img/chars public/img/props` の結果を報告して終了

# 完走ルール

16枚すべてが存在するまで打ち切らない。1枚失敗しても次へ進み、最後に未完成分を再試行する。
